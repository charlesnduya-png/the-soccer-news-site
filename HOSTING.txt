soccer.co.ke — Deploy on any Node.js host
==========================================

Live reference: https://soccercoke-alpha.vercel.app

REQUIREMENTS
- Node.js 20+ (24 recommended)
- npm
- Must run as a Node.js app (VPS, Railway, Render, cPanel "Setup Node.js App")
- This will NOT work as static PHP/HTML in public_html alone

QUICK START (do this exactly)
1. Unzip into a NEW empty folder (delete any old copy first)
2. cd into the soccer-co-ke folder
3. npm install
4. Copy .env.example to .env.local
5. Edit .env.local:
     NEXT_PUBLIC_SITE_URL=https://YOUR-DOMAIN.com
6. npm run build
7. npm start
8. Point domain / reverse proxy to that Node process (port 3000)
9. Hard-refresh browser (Ctrl+F5)

Windows: double-click START.bat
Linux/VPS: bash START.sh

VERIFY BANNERS AFTER UNZIP
These must exist or advert images will be blank:
  public/banners/janta-freebet.png
  public/banners/pilot-ke-aviator.png
  public/banners/janta-top-pool.png
  public/banners/janta-whatsapp-lottery.png
  public/banners/janta-play-win.png

Run:  node scripts/check-deploy.js

IF YOU SEE HTTP 522 / "cached or RSS fallback"
----------------------------------------------
522 = Cloudflare or proxy could not reach Node in time.

Fix:
1. Confirm Node is running:  curl http://127.0.0.1:3000
2. Confirm http://SERVER-IP:3000 works without Cloudflare
3. Cloudflare temporary test: set DNS to DNS-only (grey cloud)
4. Proxy must forward to the Node port (usually 3000), not only public_html
5. Restart after deploy: pm2 restart all   OR   npm start
6. Allow outbound HTTPS (news feeds + optional image proxy)

This build returns news faster (stale-while-revalidate) to reduce 522s.
News thumbnails load directly in the browser first (less server outbound).

cPanel
- Use Setup Node.js App / Application Manager
- Application root = unzipped soccer-co-ke folder
- Start with: npm start   (after npm install && npm run build)
- Do NOT set document root only to public_html for this project

ENVIRONMENT (.env.local)
- NEXT_PUBLIC_SITE_URL=https://your-domain.com
- GNEWS_API_KEY=   (optional)
- CRON_SECRET=long-random-string
- FOOTBALL_DATA_API_KEY=  (optional)

Shopify
- Set hub URL to your live Node/Vercel URL
- Or use https://soccercoke-alpha.vercel.app until your host is stable
