# Soccer.co.ke Shopify Theme — Upload Guide

Shows your live football site (transfers, PL news, World Cup, tables)
inside Shopify: https://soccercoke-alpha.vercel.app

## Upload (3 steps)

1. Shopify Admin → Online Store → Themes
2. Add theme → Upload zip file
3. Choose: soccer-co-ke-theme.zip → then click Publish

Done. Your store homepage shows the full football hub.

## Hub URL setting

Theme settings → Football Hub
Default: https://soccercoke-alpha.vercel.app
Do NOT set this to soccer.co.ke (that causes a blank loop).

## Optional pages

| Title     | Handle      | Template          |
|-----------|-------------|-------------------|

| World Cup | world-cup   | soccer-worldcup   |
